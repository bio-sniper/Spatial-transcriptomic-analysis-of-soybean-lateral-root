Soybean Lateral Root Spatial Transcriptome Analysis Pipeline
=============================================================
Author:  Lei Li
Date:    2026-07-18

=============================================================
1.  Overview
=============================================================

This pipeline analyzes spatial transcriptomics data of soybean (Glycine max)
lateral root primordium (LRP) and overlying cortex tissues. It covers:

  - Quality control & filtering
  - Data integration (Harmony)
  - Clustering & UMAP visualization
  - Marker gene detection & cell proportion analysis
  - hdWGCNA (co-expression network analysis)
  - GO enrichment analysis
  - Monocle3 pseudotime trajectory analysis (LRP + cortex)
  - Phytohormone pathway activity scoring
  - Hydraulic / mechanical force modeling

The entry point is run_analysis.R, which sources scripts 01-09 sequentially.
Alternatively, each script can be run independently.

=============================================================
4.  How to Run
=============================================================

Full pipeline (recommended):

  set OUTPUT_DIR=G:\path\to\project_4\output_run
  "D:\Program Files\R\R-4.4.2\bin\Rscript.exe" run_analysis.R

Single script (e.g., script 07):

  set OUTPUT_DIR=G:\path\to\project_4\output_run
  "D:\Program Files\R\R-4.4.2\bin\Rscript.exe" scripts/07-lr-subcluster-monocle.R

Output directory is controlled by the OUTPUT_DIR environment variable.
Default fallback is "results/" if OUTPUT_DIR is not set.

=============================================================
5.  Script Details
=============================================================

--- 01-setup.R ---
  Purpose: Load libraries, create output directories, define paths.
  Input:   None (uses OUTPUT_DIR env var)
  Output:  Figures/, Tables/, Objects/ directories created
  Used by: All subsequent scripts (sourced via run_analysis.R)

--- 02-integration-clustering.R ---
  Purpose: Load ST_LR_merged.rds, run Harmony integration,
           perform clustering (0.4 resolution), generate UMAP plots.
  Input:   data/ST_LR_merged.rds
  Output:  figures/spatial_cluster.jpg (Figure 2B-I)
                figures/umap_clusters.jpg (Figure 2A)
                figures/umap_by_chip_id.jpg (Figure S2D)
                objects/LR_cluster.rds

--- 03-markers-cell-proportion.R ---
  Purpose: Find all markers per cluster, generate dotplot & circle plot,
           compute cell proportions across samples.
  Input:   data/ST_LR_merged.rds
  Output:  figures/cell_proportion.jpg (Figure 2L)
                figures/marker_gene_circle.tif (Figure 2K)
                tables/marker_genes.csv

--- 04-quality-control.R ---
  Purpose: QC violin plots (nCount, nFeature, percent.mt), spatial QC,
           feature scatter plot, sample correlation heatmap.
  Input:   objects/LR_cluster.rds
  Output:  figures/qc_vlnplot_ST_merged.jpg (combined plot of Figure S2A-C)
           figures/nCount_Spatial_ST_merged.jpg (Figure S2A)
           figures/nFeature_Spatial_ST_merged.jpg (Figure S2B)
           figures/percent_mt_ST_merged.jpg (Figure S2C)
           figures/feature_scatter_ST_merged.jpg (Figure S2E)
           tables/QC_summary_13samples.csv

--- 05-hdWGCNA.R ---
  Purpose: Co-expression network analysis using hdWGCNA.
           Constructs metacells, computes modules, generates network
           dendrogram, module UMAPs, radar plot, per-module network
           plots, and hub gene tables. Falls back to VariableFeatures
           if bulk module data is unavailable.
  Input:   objects/ST_LR_merged.rds (or ST_LR_WGCNA_finished.rds if exists)
  Output:  figures/hdWGCNA_dendrogram.tif
           figures/hdWGCNA_module_umap.jpg
           figures/hdWGCNA_network.pdf
           figures/hdWGCNA_radar_plot.jpg
           figures/ModuleNetworks/*.pdf  (7 per-module networks)
           tables/Top25_Hub_Genes_brown.csv
           tables/Top25_Hub_Genes_turquoise.csv
           tables/Top25_Hub_Genes_blue.csv
           objects/ST_LR_WGCNA_finished.rds

--- 06-go-enrichment.R ---
  Purpose: GO enrichment (biological process) for hdWGCNA modules.
  Input:   data/ST_LR_merged.rds (for gene list)
  Output:  GO enrichment plots per module

--- 07-LR-subcluster-monocle3.R ---
  Purpose: Monocle3 pseudotime trajectory for:
           (a) LRP cells (from LR_LRP.rds)
           (b) Overlying cortex cells (from LR_overlying cortex.rds)
  Input:   objects/LR_LRP.rds
           objects/LR_overlying cortex.rds
  Output:  figures/LR_LRP_pseudotime_monocle3.jpg
           figures/LR_LRP_module_heatmap.jpg
           figures/LR_LRP_targeted_genes.jpg
           figures/LR_cortex_pseudotime_monocle3.jpg
           figures/LR_cortex_expression_modules.jpg
           figures/LR_cortex_module_heatmap.jpg
           tables/pseudotime_DEG_LR_LRP.csv
           tables/pseudotime_DEG_LR_overlying_cortex.csv
           tables/LR_LRP_gene_expression_module_analysis.csv
           tables/LR_cortex_gene_expression_module_analysis.csv
           GO_results_LRP/ (21 module CSVs)
           GO_results_cortex/ (7 module CSVs)
           figures/GO_plots_LRP/ (21 dotplots)
           figures/GO_plots_cortex/ (7 dotplots)

--- 08-phytohormones.R ---
  Purpose: Score and visualize phytohormone pathway activities
           (auxin, cytokinin, GA, ABA, BR, ET, JA, SA, ARF, IAA).
  Input:   objects/LR_cluster.rds
  Output:  figures/*_violin_plot.jpg
           figures/*_spatial_plot.jpg
           figures/*_score_projection.jpg
           tables/Hormone_ModuleScores.csv

--- 09-hydraulic-mechanics.R ---
  Purpose: Load Bulk-RNA time-series data, compute mechanical force
           asymmetry index, generate burst profile plots and
           mechanosensitive gene correlation.
  Input:   data/Bulk-RNA-summary-2026-03.csv
           objects/LR_cluster.rds
  Output:  figures/mechanical_force_all_stages.jpg
           figures/asymmetric_force_burst.jpg
           figures/LDL2_KO_mechanical_force.jpg
           figures/LOX1_spatial_score.jpg
           figures/stage2_LOX1_vlnplot.jpg

--- utils.R ---
  Purpose: Shared utility functions sourced by other scripts:
    run_module_go_enrichment()       -- GO + bar plot per module
    run_monocle3_trajectory()        -- Full Monocle3 pipeline
    run_pseudotime_module_analysis() -- Gene module analysis
    run_module_go_loop()             -- Batch GO for modules
    run_module_score_loop()          -- Module score + violin plots
    run_spatial_score_loop()         -- Module score spatial plots
